Panorama des Solutions

Il existe plusieurs approches pour virtualiser un système.
Voici les distinctions fondamentales entre les solutions du marché.

Hyperviseur Type 1

"Bare Metal"

S'installe directement sur le matériel physique. C'est la solution privilégiée des Data Centers pour sa performance brute.

Hyperviseur Type 2

"Hosted"

S'installe comme un logiciel sur votre OS (Windows/Mac). Idéal pour le développement et les tests locaux.

Conteneurisation

"Micro-services"

Plus léger que la virtualisation classique. Partage le noyau de l'OS hôte (ex: Docker). Très prisé des développeurs web.

Comparatif Technique

Type Performance Usage Recommandé Exemples
