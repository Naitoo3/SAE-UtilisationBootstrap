# SAE sur l'utilisation du framework Bootstrap:

## A propos :
  Cette Situation d'apprentissage et d'évaluation met en avant l'utilisation de Bootstrap afin de créer un site WEB responsive, s'adaptant à chaque type d'écran.
  Notre but, est de présenter les avantages des machines virtuelles, montrer comment procéder à une installation de façon détaillée, et ainsi la mise en ligne de notre rapport de SAE.
  
## Arborescence des fichiers :
```text
.
├── Assets/
│   ├── CSS/
│   │   ├── bootstrap.min.css
│   │   └── style.css            # Feuille de style personnalisée
│   ├── Images/                 # Ressources graphiques et illustrations
│   └── Doc/                    # Rapport de la SAÉ (disponible dans outils.html)
├── index.html                  # Page d'accueil
├── concepts.html               # Page dédiée aux concepts théoriques
├── outils.html                 # Page regroupant les outils et ressources
└── tutoriels.html              # Page des guides et tutoriels
```
## Mise en route :
D'abord, téléchargez le zip sur le Github, et lancer l'extraction dans le répértoire de votre choix.
Par la suite, Lancez le "index.html", et par la suite, tout doit fonctionner.
